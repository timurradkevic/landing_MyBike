# MyBike Landing Page

A responsive landing page for MyBike, showcasing modern bicycles, their features, and contact information. The project is built with semantic HTML and SCSS, following responsive design principles to provide a smooth user experience across mobile, tablet, and desktop devices.

## Live Preview

🔗 **Demo:** https://timurradkevic.github.io/landing_MyBike/

## Design Reference

🎨 **Figma Design:** https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1

## Technologies Used

* HTML5
* SCSS (Sass)
* JavaScript (ES6)
* BEM Methodology
* Responsive Web Design
* CSS Grid
* Flexbox

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/mybike-landing-page.git
cd mybike-landing-page
```

### Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

### Run the project locally

```bash
npm start
```

or

```bash
yarn start
```

## Features

* Responsive layout for mobile, tablet, and desktop screens
* Smooth navigation through page sections
* Interactive mobile menu
* Product showcase section
* Detailed bike feature gallery
* Contact form
* Hover and focus states for improved user experience
* Built using BEM naming conventions
* SCSS architecture with reusable variables and mixins
